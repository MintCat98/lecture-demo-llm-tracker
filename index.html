KoTranslate 테스트

translator-ko.js가 이 브라우저에서 동작하는지 확인하는 더미 페이지입니다.

1. 환경 확인과 모델 준비

처음에는 번역 모델 다운로드가 필요해서, 반드시 버튼을 눌러 준비해야 합니다.

Translator API확인 중
한 → 영 모델확인 중
영 → 한 모델확인 중
on-device LLM (Prompt API)확인 중

2. 직접 번역

여러 줄도 줄 단위로 번역합니다. 한글이 없는 줄(URL, 가격)은 그대로 둡니다.

3. LLM 연결 흐름

원문(한국어) → 영어 → LLM 요약(영어, JSON) → 지정 필드만 한국어. Prompt API가 없으면 가짜 LLM으로 흐름만 확인합니다.
